Interactive particle sandbox

A fast, creative falling sand game built for endless experiments

This falling sand game turns your browser into a compact physics laboratory. Drop grains of sand, pour water into tunnels, grow plants, ignite oil, freeze lakes, melt metal and use wind to push smoke and fire across the screen. Every pixel is a material with its own behavior, so small changes can create surprising chain reactions.

Unlike a static falling sand art game, this sandbox is designed around interaction. You can draw terrain, build a shelter for people, start a controlled fire, release zombies or make a volcano. The simulation runs locally with HTML5 Canvas, so the core game starts instantly without a login or a falling sand game download.

How to play

Build your first reaction in under a minute

A good dropping sand game should be understandable without a long tutorial. Start with these four steps, then invent your own systems.

Choose a material

Select sand, water, fire, lava, plant, ice or another element from the horizontal toolbar.

Draw on the sandbox

Drag with a mouse or finger. Increase brush size for terrain, then reduce it for wires, walls and precise reactions.

Combine elements

Try water above sand, fire beside wood, lava under ice, plant near water or acid above metal.

Control and save

Pause to edit safely, change wind, undo the last drawing action and save your final scene as a PNG image.

Common questions

Falling sand game FAQ

What is a falling sand game?

It is a particle-based sandbox built from a grid of small cells. Each cell follows simple material rules: powders fall, liquids spread, gases rise and active materials exchange heat or trigger reactions. Together, those rules create fluid-looking motion and emergent scenes.

Is this falling sand game online and free?

Yes. This is a falling sand game online that runs inside the page at no charge. There is no required account and no separate installer.

Is this the original falling sand game?

No single page owns the general falling-sand genre. This is an original browser implementation inspired by classic cellular sandbox ideas. It is not presented as the source code or exact copy of another game.

Can I download the game?

The current build is designed for the browser. The Save button downloads your artwork as a PNG. A dedicated offline or installable edition can be added later as a Progressive Web App.

Why does the simulation resolution look pixelated?

Each visible block represents a simulated cell. A moderate resolution keeps the world responsive while thousands of particles move and react every frame. The game automatically increases detail on larger screens when performance allows.

What should I try first?

Build a bowl with Wall, fill it with Water, pour Sand from above, add Plant at one edge and light Wood with Fire. Then increase wind and watch smoke move across the sandbox.
